# FORMA — студия инфографики

MVP инструмента для визуализации числовых и текстовых таблиц. Минималистичный интерфейс в духе раннего Braun: светлый фон, чёрная типографика, прямые углы.

## Запуск

Требуется Node.js 20.19+ или 22.12+ (проверено на Node.js 24).

```sh
npm ci --cache /tmp/forma-npm-cache
npm run dev
```

```sh
npm test           # Проверка чисел, палитры, безопасного SVG и композиций
npm run build     # Production-сборка в dist/
npm run preview   # Просмотр production-сборки
npm run test:browser # Сквозная проверка production-сборки в Chromium
```

Для браузерной проверки используется системный `/usr/bin/chromium`, либо `CHROMIUM_PATH`, либо браузер Playwright (`npx playwright install chromium`). Скрипт самостоятельно запускает preview на свободном порту 4175 и останавливает его после проверки.

## Сценарий

1. Добавьте изображения PNG, JPG, WEBP, GIF, AVIF или BMP. Они сохраняются в библиотеке текущего браузера; карточки можно открывать, выбирать вместе и удалять. Примеры в библиотеке созданы для этого MVP.
2. Загрузите XLSX, XLS, CSV, TSV, ODS или JSON. Первая непустая строка — заголовки. JSON — массив объектов или массив строк. Выберите лист и столбцы подписей и значений. Можно проверить первые строки таблицы перед генерацией.
3. Укажите заголовок, краткое пояснение и при необходимости до 20 цветов HEX через пробел, запятую или точку с запятой. Если палитра пустая, используются цвета выбранных референсов.
4. Сгенерируйте три варианта. Числовые таблицы получают линейную, типографическую и распределительную композиции; текстовые — обзор, редакционную и модульную. Скачайте SVG или PNG.

Числовые данные сохраняют нулевые и отрицательные значения, десятичные запятые и проценты Excel. Для отрицательных значений распределение заменяется диаграммой относительно нуля. Некорректные и пустые записи пропускаются с сообщением о количестве. Смешанный столбец с числами и текстом трактуется как числовой: текстовые записи пропускаются.

## Границы MVP

Генерация выполняется локально по SVG-композициям. Изображения задают палитру и насыщенность типографики по анализу пикселей; выбранные референсы объединяют эти параметры. Семантическое распознавание изображения, свободная генерация дизайна через ИИ и интерпретация пожеланий на естественном языке пока не подключены. Поле пояснения размещает текст в инфографике.

Файлы не отправляются на сервер. Референсы сохраняются в localStorage только в этом браузере; таблица, настройки и результаты живут в памяти страницы. Нет аккаунтов и облачной синхронизации. При нехватке localStorage изображение остаётся доступно только до закрытия страницы. Загрузка ограничена 10 МБ на файл, генерация — 100 записями. Для больших текстовых записей есть ограничения длины.

SVG можно редактировать в векторном редакторе. PNG обычно экспортируется в двойном разрешении; очень длинные композиции автоматически уменьшаются до безопасного размера canvas. SVG использует системный Arial/Helvetica. Manrope для интерфейса поставляется локально, без запросов к Google Fonts.

## Технологии

Vite, JavaScript, SheetJS для таблиц, Canvas для анализа изображений и PNG-экспорта, SVG для инфографики. Для подключения ИИ потребуется отдельный серверный endpoint; секретный API-ключ нельзя хранить в браузере.

## GitHub Pages

Сайт собирается с базовым путём `/infographics/` командой `npm run build:pages`. Ветка `gh-pages` содержит готовые статические файлы и `.nojekyll`. В GitHub откройте Settings → Pages: Source **Deploy from a branch**, Branch **gh-pages**, Folder **/(root)**, затем Save. Ожидаемый адрес после успешной публикации: https://antonryndyathedesigner.github.io/infographics/.

Workflow `.github/workflows/pages.yml` проверяет и собирает изменения в `main`, затем обновляет `gh-pages`. Для работы workflow в настройках репозитория должны быть разрешены GitHub Actions и запись через `GITHUB_TOKEN`. Сам workflow не включает Pages; источник публикации выбирается в Settings → Pages.
