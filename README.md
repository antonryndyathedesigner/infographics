# Инфографика

Минималистичный локальный инструмент для числовых и текстовых таблиц. Без брендинга и встроенных примеров.

## Запуск и проверки

Требуется Node.js 20.19+ или 22.12+ (проверено на Node 24).

```sh
npm ci --cache /tmp/forma-npm-cache
npm run dev
npm test
npm run build
npm run test:browser
```

Браузерная проверка сама запускает production preview на порту 4175. Используется `/usr/bin/chromium`, `CHROMIUM_PATH` или установленный браузер Playwright (`npx playwright install chromium`).

## Работа

1. Загрузите собственные референсы PNG, JPG, WEBP, GIF, AVIF или BMP. Выберите один или несколько. Референсы можно просматривать, удалять и сохранять в библиотеке этого браузера.
2. Загрузите XLSX, XLS, CSV, TSV, ODS или JSON; выберите лист и столбцы. Первая непустая строка — заголовки. JSON — массив объектов или строк. Нули, отрицательные значения, десятичные запятые и проценты Excel поддерживаются.
3. При необходимости задайте заголовок, пояснение и до 20 HEX-цветов. Пустая палитра использует цвета референсов.
4. Сгенерируйте три варианта. Выберите результат и уточните его в поле «Правки».
5. Нажмите «Скачать SVG» для редактируемой векторной графики или PNG для растрового изображения. Экспорт включает применённые правки.

## Анализ референсов

Локальный анализ пикселей выделяет палитру, фоновый цвет, плотность элементов, контраст и геометрию крупных форм. По их пропорциям выбираются полосы, столбцы, кольцевая диаграмма или карточки. Несколько референсов объединяют цвета и геометрические признаки; фон, плотность и насыщенность текста усредняются. Старые сохранённые изображения анализируются при следующей генерации.

Это эвристический анализ геометрии, а не семантическое распознавание дизайна через ИИ. Плотные иллюстрации, скриншоты с интерфейсом, сложные диаграммы и соединённые элементы могут классифицироваться неточно. Полное воспроизведение визуального языка референса и свободная генерация требуют внешней модели и серверного endpoint; их здесь пока нет.

Для отрицательных значений и нулевой суммы вместо кольцевой диаграммы строятся полосы. Для более 12 категорий вместо столбцов — полосы. Текстовые таблицы получают обзор, текстовую композицию и модули.

## Текстовые правки

Команды вводятся по одной на строке или через точку с запятой:

- `Убери линии`, `убери подписи`, `убери числа`, `убери заголовок`.
- `Покажи линии`, `покажи подписи`, `покажи числа`, `покажи заголовок`.
- `Увеличь текст`, `уменьши текст`, `больше воздуха`, `компактнее`.
- `Заголовок: новое название`, `цвет: #D8E568`.
- `Сортируй по убыванию`, `сортируй по возрастанию` (числовые данные).
- `Убери «Название категории»` (точное название без учёта регистра).
- `Кольцевая`, `столбцы`, `полосы`, `карточки` (числовые данные).

Правки применяются к текущему результату. Нераспознанные команды явно перечисляются; они не выдаются за выполненные. Последние 20 шагов можно отменять. Удаление всех записей отклоняется. Повторная генерация начинает с исходной таблицы и настроек. Произвольные запросы на естественном языке пока не интерпретируются.

## Хранение и ограничения

Файлы не отправляются на сервер. Изображения сохраняются в localStorage текущего браузера; таблица, результаты и правки — в памяти страницы. Изображения ужимаются до 1200 px по длинной стороне. При переполнении localStorage появляется предупреждение. Загрузка — до 10 МБ на файл, генерация — до 100 записей, подпись — до 300 символов, текст — до 1500. В смешанном числовом столбце нечисловые строки пропускаются с уведомлением.

SVG — векторные формы и текст, без логотипа и служебных подписей. Используется системный Arial/Helvetica. PNG обычно экспортируется в двойном разрешении; длинные изображения уменьшаются до безопасного размера canvas. Manrope для интерфейса поставляется локально.

## GitHub Pages

```sh
npm run build:pages
```

Workflow `.github/workflows/pages.yml` проверяет и собирает изменения в `main`, затем обновляет `gh-pages`. Pages должен быть включён: Settings → Pages → Deploy from a branch → gh-pages → /(root). Адрес: https://antonryndyathedesigner.github.io/infographics/.
